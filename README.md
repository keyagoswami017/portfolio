# Keya Goswami | Portfolio Website

A clean, modern, and responsive developer portfolio website showcasing my professional experience, cloud infrastructure projects, test automation solutions, and education.

Live Demo: [keya-portfolio.vercel.app](https://keya-portfolio.vercel.app)

---

## 🛠️ Built With

* **HTML5 & CSS3** - Semantic structure and custom styling
* **Tailwind CSS** - Modern utility-first styling (via CDN)
* **Lucide Icons** - Clean modern SVG icons
* **Vercel** - Fast, continuous deployment linked to GitHub

---

## 🚀 Features

* **Hero Section:** Introduction, quick contact links, and direct access to GitHub & LinkedIn profiles.
* **Professional Summary:** Overview of my 8 years of experience across software engineering, enterprise automation, and DevOps.
* **Work Experience:** Detailed history of roles at Accenture, TietoEVRY, and Atos.
* **Interactive Projects Scroller:** Smooth horizontal carousel highlighting 6 major projects including *VeriCode*, *Cloud Native Infrastructure*, *Selenium Test Automation*, *Secure REST API*, *FindMeSeat*, and *Parkbnb*.
* **Education & Credentials:** Overview of MS in Software Engineering at Northeastern University and BS in Computer Science.
* **Contact & Resume Download:** Direct link to view/download my latest resume.

## 💻 Local Setup & Development

No complex build setup or node dependencies required. To run this project locally:

1. Clone this repository:
   ```bash
   git clone [https://github.com/keyagoswami017/portfolio.git](https://github.com/keyagoswami017/portfolio.git)
   ```
2. Navigate into the folder:
    ```bash
    cd portfolio
    ```
3. Open index.html in your favorite browser.
